# Wisdom Circle Story Engine

**All-ages collaborative story creation for connection, imagination, and shared wisdom.**

Wisdom Circle is a gentle, local-first story engine that helps people of every age co-create meaningful stories. It draws on timeless human themes — curiosity, kindness, courage, belonging — while remaining fully respectful of diverse worldviews.

> **Important Note**  
> This is a creative companion for storytelling and reflection. It is **not** therapy, diagnosis, or crisis support.  
> If you or someone you know is in distress, please reach out to trusted people or professional resources (e.g., 988 in the US).

## Why it exists

Stories are one of the oldest ways humans make sense of life, pass on values, and feel less alone. Wisdom Circle gives families, classrooms, friends, and individuals a simple space to build those stories together — without ads, tracking, or pressure to “perform.”

## Core Features (MVP Vision)

- **Age-adaptive prompts** — gentle guidance that grows with the tellers (child, teen, adult, elder)
- **Shared circle mode** — take turns adding lines, images, or choices
- **Wisdom seeds** — optional starting themes drawn from universal human experiences (friendship, wonder, repair, gratitude) rather than any single doctrine
- **Local-first** — stories stay on your device by default
- **Export** — plain text, Markdown, or printable storybook format
- **Accessibility first** — screen-reader friendly, high-contrast options, keyboard navigation, reduced-motion support

## Getting Started

This repository is currently in early scaffolding.

1. Clone the repo  
   ```bash
   git clone https://github.com/irecov3r3d/Wisdom-Circle-story-engine.git
   cd Wisdom-Circle-story-engine
   ```
2. The project is designed to run with minimal dependencies. Future iterations will include a simple HTML/JS interface that opens directly in the browser.

## Design Principles

- **Safety** — no dark patterns, no surprise content, clear consent for sharing
- **Clarity** — every interaction explains what happens next
- **Access** — usable on low-end devices, offline-capable, multilingual-ready
- **Reach** — works for mixed-age groups and solo reflection alike
- **Respect** — themes are offered as invitations, never requirements

## Roadmap (prioritized)

1. Single-page story circle (HTML + vanilla JS)
2. Prompt library with age filters
3. Export to PDF / Markdown
4. Optional local AI assistance (user-supplied key, fully transparent)
5. Shared room mode (WebRTC or simple link)
